## Dataset Description 
### 1. BUSI Dataset
The Breast Ultrasound Images (BUSI) dataset is used as the primary dataset for training and testing the proposed Hybrid Deep Learning framework for breast cancer detection and segmentation. The dataset consists of ultrasound breast images categorized into benign, malignant, and normal classes, along with their corresponding tumor mask annotations. The dataset is utilized for model development, segmentation learning, classification analysis, and performance evaluation of the proposed framework.

Download the dataset from the following URL and extract it.
The dataset is available [Kaggle Website](https://www.kaggle.com/datasets/anaselmasry/datasetbusiwithgt/data)


### 2. BUSBRA Dataset
The BUSBRA dataset [135](https://aapm.onlinelibrary.wiley.com/doi/10.1002/mp.16812) is used for external validation to evaluate the generalization capability and robustness of the proposed Hybrid Deep Learning framework on unseen breast ultrasound data. This dataset enables cross-dataset validation by assessing the performance consistency of the trained model under different imaging characteristics, lesion distributions, and data acquisition conditions. The external validation analysis demonstrates the capability of the proposed framework to maintain reliable performance beyond the primary training dataset.

This dataset is obtained from the following reference and is available at the URL.
The dataset is available [Zenodo Website](https://zenodo.org/records/8231412) and [Github Repository](https://github.com/wgomezf/BUS-BRA)
